# Спутниковый трекер

Информационно-аналитическое приложение для работы с данными о космических аппаратах. Позволяет вести базу данных спутников, вычислять их положение в пространстве, строить статистические отчёты и графики, а также визуализировать наземные траектории.

## Возможности

- Ведение базы данных спутников (NORAD ID, название, страна, орбитальные параметры, TLE-строки)
- Импорт и экспорт данных в формате CSV
- Расчёт декартовых и географических координат спутника на заданный момент времени
- Формирование текстовых статистических отчётов (высоты, наклонения, распределение по странам и годам)
- Построение графиков и диаграмм (гистограммы, круговые диаграммы, графики запусков)
- Визуализация наземной траектории спутника на карте
- Поддержка русского и английского языков
- Светлая и тёмная темы оформления

## Требования

- Операционная система: Windows 10/11, Linux, macOS
- Python 3.9 – 3.11
- Библиотеки: pandas, numpy, matplotlib (все входят в состав дистрибутива Anaconda)

## Установка

Использование Anaconda

1. Установите дистрибутив Anaconda с официального сайта
2. Скопируйте файлы проекта в любую папку
3. Запустите приложение из Anaconda Prompt:

```bash
cd путь к папке/
py main.py
```

## Где хранятся файлы

| Тип файла | Путь | Формат |
|-----------|------|--------|
| База спутников | Storage/satellites.csv | CSV |
| Бинарная база | Storage/dataSet_дата_время.pkl | Pickle |
| Текстовые отчёты | Output/Reports/Report_тип_дата_время.txt | TXT |
| Графики | Output/Graphics/Graphic_тип_дата_время.png | PNG |
